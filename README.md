# Codes — Projects

## 📚 cbse-papers-app (this repo's main project)

A complete, publishing-ready **CBSE Previous Year Question Papers app** for Google Play:

- Classes **5, 8, 10, 12** — every subject
- Official CBSE board papers (Class 10 & 12, 2023–2026 + compartment) & official sample
  papers (2020-21 → 2025-26), streamed from `cbse.gov.in`
- Offline reading, favourites, search, import-your-own-papers
- Built with React + Vite + Capacitor 8 (native Android project included, with icons & splash)
